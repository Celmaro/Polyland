## 1. المتطلبات الأساسية

قبل البدء، تحتاج إلى ثلاثة أشياء:

### 💻 متطلبات الكمبيوتر
- **نظام التشغيل**: Windows، Mac، أو Linux.
- **Node.js**: يجب تثبيت Node.js (الإصدار 18 أو أحدث).
  - [حمل Node.js من هنا](https://nodejs.org/) (اختر نسخة "LTS").
- **Git**: مطلوب لتحميل الكود.
  - [حمل Git من هنا](https://git-scm.com/).

### 💰 متطلبات المحفظة
- **حساب Polymarket**: سجل الدخول إلى [Polymarket.com](https://polymarket.com).
- **رصيد USDC (على شبكة Polygon)**: تحتاج إلى أموال للتداول.
  - تأكد من استخدام **USDC.e** وهو الرمز المعتمد في بولي ماركت.
- **رصيد MATIC (على شبكة Polygon)**: تحتاج مبلغاً صغيراً (1-5 دولار) لدفع رسوم الشبكة (Gas).

### 🔑 المفتاح الخاص (Private Key)
- تحتاج إلى **المفتاح الخاص** لمحفظتك (يمكن استخراجه من MetaMask أو محفظة بولي ماركت).
- *ملاحظة أمنية: لا تشارك هذا المفتاح مع أي شخص أبداً.*

## 2. التثبيت

افتح التيرمينال (Command Prompt أو PowerShell في ويندوز، Terminal في ماك) ونفذ الأوامر التالية واحداً تلو الآخر.

### الخطوة 1: تحميل الكود (Clone)
```bash
git clone https://github.com/MrFadiAi/Polymarket-bot.git
cd Polymarket-bot
```

### الخطوة 2: تثبيت الحزم وبناء لوحة التحكم
```bash
# تثبيت الحزم الأساسية
npm install

# بناء لوحة التحكم (خطوة ضرورية!)
cd dashboard
npm install
npm run build
cd ..
```

*قد تستغرق هذه العملية دقيقة إلى 3 دقائق.*

## 3. الإعداد والتكوين

هذه هي الخطوة الأهم. نحتاج لربط البوت بمحفظتك.

### الخطوة 1: إنشاء ملف .env
1. ابحث عن الملف المسمى `.env.example` في المجلد.
2. قم بنسخه وإعادة تسمية النسخة إلى `.env`.

### الخطوة 2: إضافة بياناتك
```env
# ==============================================
# 🔑 إعدادات المحفظة (مطلوب)
# ==============================================

# مفتاح المحفظة الخاص (Private Key)
POLYMARKET_PRIVATE_KEY=0xYourPrivateKeyHere

# ==============================================
# ⚙️ إعدادات البوت
# ==============================================

# رأس المال (ميزانية المخاطرة - وليس رصيد محفظتك الكامل)
# يحدد أحجام الصفقات وحدود المخاطر
# ابدأ بمبلغ صغير للاختبار
CAPITAL_USD=250

# وضع التشغيل التجريبي (DRY RUN)
# "true" = وضع المحاكاة (آمن للتجربة)
# "false" = تداول حقيقي (كن حذراً)
DRY_RUN=true

# 🆕 إدارة المخاطر (اختياري - القيم الافتراضية محافظة)
DAILY_MAX_LOSS_PCT=0.05      # حد خسارة يومي 5%
MONTHLY_MAX_LOSS_PCT=0.15    # حد خسارة شهري 15%
MAX_DRAWDOWN_PCT=0.25        # حد انخفاض من القمة 25%
TOTAL_MAX_LOSS_PCT=0.40      # حد خسارة إجمالي 40% = إيقاف نهائي
```

**⚠️ هام جداً:**
- ابدأ بـ `DRY_RUN=true` و`CAPITAL_USD=50` للاختبار
- غيّر إلى `DRY_RUN=false` فقط عندما تتأكد 100%

## 5. دليل لوحة التحكم

لوحة التحكم هي مركز القيادة مع **مراقبة محسّنة للمخاطر**.

### اللوحات الرئيسية
- **مؤشر الوضع**: يظهر **🔴 LIVE** أو **🟢 DRY RUN**
- **زر التبديل**: تبديل فوري بين الأوضاع
- **الأرصدة**: عرض فوري لـ MATIC و USDC
- **لوحة PnL**: تتبع الأرباح/الخسائر

### 🆕 لوحة حالة المخاطر
- **الحد اليومي**: استخدام حد الخسارة اليومي 5%
- **الحد الشهري**: استخدام حد الخسارة الشهري 15%
- **الانخفاض**: الانخفاض الحالي من ذروة رأس المال
- **المتتابعات**: عداد الأرباح/الخسائر المتتالية
- **مؤشرات الحالة**: 🔴 تجاوز أو ✅ آمن

### إجراءات سريعة
- **تبديل الاستراتيجيات**: تفعيل/إيقاف فوري
- **إيقاف طارئ**: وقف التداول فوراً
- **بيع الذعر**: إغلاق جميع المراكز (بحذر)

## 6. إدارة المخاطر

### 🆕 نظام حماية متعدد الطبقات

البوت الآن لديه **4 طبقات من الحماية** لص safeguard رأس مالك:

#### الطبقة 1: حد الخسارة اليومي (5%)
- **الوظيفة**: يوقف التداول عند خسارة 5% في يوم واحد
- **الإجراء**: إيقاف لمدة 60 دقيقة، ثم استئناف
- **مثال**: مع رأسمال 250$، يتوقف عند خسارة 12.50$ يومياً

#### الطبقة 2: حد الخسارة الشهري (15%)
- **الوظيفة**: يوقف التداول عند خسارة 15% في 30 يوماً
- **الإجراء**: إيقاف لمدة 30 يوماً (باقي الشهر)
- **مثال**: مع رأسمال 250$، يتوقف عند خسارة 37.50$ شهرياً

#### الطبقة 3: حد الانخفاض من القمة (25%)
- **الوظيفة**: يراقب الانخفاض من ذروة رأس المال
- **الإجراء**: إيقاف لمدة 7 أيام عند التجاوز
- **مثال**: ذروة 300$، يتوقف إذا انخفض لأقل من 225$

#### الطبقة 4: الإيقاف النهائي (40%)
- **الوظيفة**: **إيقاف نهائي** عند خسارة إجمالية 40%
- **الإجراء**: توقف كامل، يتطلب إعادة تشغيل يدوي
- **مثال**: مع رأسمال 250$، يتوقف نهائياً عند خسارة 100$

### 🆕 التحجيم الديناميكي للصفقات

البوت الآن **يكيّف أحجام الصفقات** تلقائياً:

- **الحجم الأساسي**: 2% من رأس المال (انخفض من 3%)
- **عند الخسائر**: يقلل بنسبة 20% لكل خسارة متتالية
- **عند الأرباح**: يزيد بنسبة 10% لكل ربح متتالي (محدود بـ 5%)
- **مثال**:
  - عادي: 250$ × 2% = 5$/صفقة
  - بعد 3 خسائر: 5$ × 0.8 × 0.8 = 3.20$/صفقة
  - بعد 5 أرباح: 5$ × 1.4 = 7$/صفقة (محدود بـ 12.50$)

## 7. شرح الاستراتيجيات

### 1. ⚖️ المراجحة (Arbitrage)
- **الفكرة**: إيجاد أسواق حيث `نعم + لا < $1.00`
- **الإجراء**: شراء كلا الجانبين فوراً
- **🆕 v3.1**: حد ربح أعلى (1%) لتغطية رسوم الغاز
- **المخاطرة**: منخفضة جداً

### 2. 📉 صيد الانخفاضات (DipArb)
- **الفكرة**: مراقبة البيع الهلعي في أسواق 15 دقيقة
- **المحفز**: انهيار >15% في 3 ثوانٍ
- **🆕 v3.1**: حد أدنى 1.50$ (جميع المراكز قابلة للإغلاق)
- **المخاطرة**: منخفضة-متوسطة

### 3. 🐋 المال الذكي (🆕 محسّن)
- **الفكرة**: تتبع أفضل المتداولين
- **🆕 تصفية صارمة**:
  - ✅ حد أدنى 60% نسبة ربح (زيادة من 50%)
  - ✅ حد أدنى 500$ ربح إجمالي (زيادة من 100$)
  - ✅ نسبة أرباح ≥ 1.5x (أرباح/خسائر)
  - ✅ نقاط تناسق 70%+ (أداء حديث)
  - ✅ لا صفقات ضخمة (حد أقصى 30% من الربح من صفقة واحدة)
- **المخاطرة**: متوسطة

### 4. ⚡ التداول المباشر
- **المميزات**: FOK، القنص
- **🆕 v3.1**: وقف خسارة (15%)، جني أرباح (25%)، حد زمني (7 أيام)
- **المخاطرة**: متحكّم بها

## 8. حل المشاكل

**"Command not found"؟**
- تأكد من تثبيت Node.js وأعد التشغيل

**"Connection Failed"؟**
- تحقق من الإنترنت والمفتاح الخاص

**"Trade value below minimum"؟**
- هذه حماية جديدة بحد 1.50$. زد `CAPITAL_USD` أو انتظر أسعاراً أفضل

**البوت توقف فجأة؟**
- تحقق من لوحة المخاطر - ربما تجاوزت حداً
- هذه **ميزة أمان** تعمل كما هو مخطط

## 9. الأمان والمخاطر

### ✅ ميزات الأمان المدمجة (v3.1)
1. **حدود متعددة**: 4 مستويات من الحماية التلقائية
2. **تصفية المتداولين**: متابعة المثبتين فقط
3. **حدود الحجم**: حد أقصى 5% لكل صفقة
4. **قيم دنيا**: جميع المراكز قابلة للإغلاق
5. **إيقاف نهائي**: توقف عند خسارة 40%

### ⚠️ مسؤولياتك
1. **المفاتيح الخاصة**: أبقها آمنة
2. **ابدأ صغيراً**:
   - استخدم التجريبي أولاً (24-48 ساعة)
   - اختبر بـ 50$ حقيقي
   - تدرّج إلى 250$+
3. **راقب يومياً**: تحقق من لوحة المخاطر
4. **افهم الحدود**: اعرف ما يحفز كل طbقة
5. **إدارة رأس المال**: اجعل `CAPITAL_USD` ما تستطيع خسارته

### 📊 مسار الاختبار الموصى به

1. **يوم 1-2**: تجريبي (`DRY_RUN=true`, `CAPITAL_USD=50`)
2. **يوم 3-9**: مباشر اختباري (`DRY_RUN=false`, `CAPITAL_USD=50`)
3. **يوم 10+**: التوسع إذا كان مربحاً (`CAPITAL_USD=250`)

### 🚨 إجراءات الطوارئ

إذا حدث خطأ:
1. اضغط "Emergency Stop" في لوحة التحكم
2. أو اضغط `Ctrl+C` في التيرمينال
3. استخدم "Panic Sell" فقط عند الضرورة القصوى
